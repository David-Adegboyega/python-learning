# Python Learning

A collection of scripts built while learning Python fundamentals — covering
conditionals, loops, functions, OOP, file handling, and more.

## What's Included

- `bank.py` — A simple BankAccount class with deposit/withdraw methods
- `bmi.py` — BMI calculator with input validation and error handling
- `contact.py` — Contact book manager with add/search/delete functionality
- `todo.py` — To-do list manager using functions

## How to Run

Each script can be run individually with Python 3:

\`\`\`bash
python bank.py
\`\`\`

## Topics Covered

- Variables, conditionals, loops
- Functions, *args/**kwargs, scope
- Lists, dictionaries, sets
- File handling (.txt, .csv)
- Error handling (try/except)
- Object-Oriented Programming basics
- Git & GitHub version control
